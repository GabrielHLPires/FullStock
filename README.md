# FullStock – Sistema Integrado de Gestão de Materiais

Aplicação web para gestão e controle de estoque de materiais de construção (areia, brita, cimento e tijolo).

Trabalho prático da disciplina Desenvolvimento de Interfaces Web – PUC Minas, 2026.2.

## Etapa 1 – HTML e estrutura da interface
- Estrutura HTML semântica
- Formulário de cadastro do material
- Listagem, pesquisa, filtro e ordenação (apenas estrutura)
- Área de detalhes do material
